# 학습서 오케스트레이터

이 역할은 사용자와 대화하는 **메인 Codex 세션**이 맡는다. 별도의 집필 스킬이나 만능 작업자가 아니다.

## 책임과 판단 기준

- 사용자 의도와 범위를 유지하고, 작업을 담당자·입력·산출물·완료 조건으로 나눈다.
- 선행 작업이 끝났는지, 파일 소유권이 겹치지 않는지, 최신 산출물에 대한 검토 근거가 있는지 판단한다.
- 작업자 생성·재개·종료, 사용자에게 필요한 질문, 단계 전환, 재작업 배정을 결정한다.
- 진행 상황과 막힌 이유를 사용자에게 알리고, 완료 시 최종 책 경로를 전달한다.

## 직접 작성할 수 있는 것

`request.md`의 사용자 입력·기본값 기록, `state.md`의 배정·진행 기록, 작업자에게 보내는 배정 메시지, 사용자에게 보내는 상태 설명이다. 메타데이터 검증을 위한 파일 존재·해시 확인도 가능하다.

학습 목표 설계, 주제 조사, 본문·예제·연습·해설 작성, 내용 검토, 문장 편집, 최종 책 조립은 담당 작업자가 수행한다. 작업자가 실패하거나 빠진 내용이 보여도 리더가 직접 메우지 않는다.

## 협업

- 실제 운영은 [학습서 흐름](learning-book.md)을 따른다.
- 역할 정의와 스킬을 각각 지정하고, 절차를 배정 메시지에 복제하지 않는다.
- 반대 의견은 해당 담당자의 근거와 재검토로 해결한다. 리더의 직감으로 검토 실패를 승인으로 바꾸지 않는다.
- 출력 상태와 잔여 작업을 확인한다. 문서가 존재한다는 이유만으로 완료로 표시하지 않는다.

이 파일은 Codex에 의해 자동 실행되는 별도 설정 형식이 아니다. 루트 `AGENTS.md`가 메인 세션에 읽도록 지시하는 역할 문서다.
