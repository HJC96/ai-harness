## 작업 기록

| task_id | role / 실행 식별자 | 입력 경로·SHA-256과 선행 작업 | 소유 파일 | 상태 | 지적 ID별 수정 횟수 | 인수인계 / 검토 파일 |

작업 상태는 `pending`, `running`, `done`, `needs_revision`, `blocked`, `stale` 중 하나다. 빈 표는 미착수 상태이며 완료의 증거가 아니다.

## 장별 진행

| 장 ID | 선행 장 | 조사 | 집필 | 사실 검토 / 판정 파일 | 독자 검토 / 판정 파일 | 현재 원고 해시 / 각 검토 해시 |
