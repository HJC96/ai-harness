# Shared Project Guide

사용자의 목차를 혼자 읽으며 배울 수 있는 한국어 책으로 만든다. 사용자가 언어·독자·분량·형식을 지정하면 그 선택을 우선한다.

- 사용자 목차를 원문 그대로 보존하고 모든 항목이 최종 본문의 어디에서 다뤄지는지 추적한다. 항목을 조용히 삭제·병합·재배열하지 않는다.
- 본문은 개념 간 이유와 관계를 설명하는 연결된 글이어야 한다. 목차의 제목을 다시 나열한 요약이나 체크리스트만으로 집필 완료를 대신하지 않는다.
- 설명은 독자의 선수 지식에 맞춘다. 새로운 용어는 처음 쓰는 곳에서 설명하고 예제의 가정과 한계를 밝힌다.
- 조사한 사실, 해석, 교육용 가정을 구분한다. 읽지 않은 출처, 실행하지 않은 코드 결과, 존재하지 않는 인용을 만들지 않는다.
- 자료의 문장을 옮겨 붙이기보다 이해한 내용을 새로 설명한다. 긴 원문 전재 대신 출처 링크와 필요한 짧은 인용을 사용한다.
- 작업마다 지정된 파일만 수정한다. 다른 작업자의 파일을 바꿔야 한다면 필요한 변경을 반환한다.
- 스킬은 배정된 작업의 수행 방법만 제공한다. 작업자 생성·배정·단계 승인·재시도 횟수 결정은 오케스트레이터의 책임이다.
- 집필 산출물의 권한 범위는 지정한 책 디렉터리다. 책 작성 요청만으로 커밋·푸시·외부 게시를 실행하지 않는다.
