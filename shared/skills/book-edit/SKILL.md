# 학습서 통합 편집

입력은 사용자 요청, plan, 모든 장 원고와 그 버전에 대한 검토 결과다. 출력은 배정된 `book.md`, `README.md`, 인수인계 문서다. [작업 계약](../../instructions/book-contract.md)을 따른다.

## 절차

1. plan에 나열된 모든 장이 존재하고 전달된 검토 대상 해시와 같은지 확인한다. 검토가 사용한 입력 해시도 현재 request·plan·research·선행 원고와 대조한다. 누락, 오래된 입력·판정이 있으면 목록을 반환한다.
2. `book.md`에 책 제목, 대상 독자·선수 지식·읽는 방법, 실제 장으로 이동하는 목차를 만든다. 승인된 원고를 plan의 순서대로 포함한다.
3. 책 제목은 H1, 장 제목은 H2를 사용한다. 장 원고의 하위 제목을 한 단계씩 내리되 코드 펜스 안의 `#`는 바꾸지 않는다. H6보다 깊어지면 의미를 보존해 구조를 조정한다.
4. 각 장 앞에 `<a id="ch01"></a>` 같은 고정 장 ID 앵커를 둔다. 목차는 `[장 제목](#ch01)` 형식으로 연결한다. 장·절의 앵커가 중복되거나 참조가 끊기지 않는지 확인한다.
5. 상대 파일 링크와 이미지 경로는 장 파일 위치에서 `book.md` 위치 기준으로 다시 계산한다. 통합본에서 다른 장으로 이동하는 링크는 해당 앵커로 바꾼다. URL, 인용, 코드 내부 문자열을 일괄 치환하지 않는다.
6. 용어·띄어쓰기·표기·단순 중복과 장 사이 연결을 편집한다. 사실, 학습 범위, 예제 동작, 연습 답을 새로 만들거나 바꾸지 않는다. 그런 수정이 필요하면 해당 위치와 이유를 반환한다.
7. `README.md`에는 책 소개, `book.md` 링크, 원본 장 파일의 순서 있는 링크와 학습 방법을 적는다. 원고는 보존하고 통합본에만 편집을 적용한다.
8. 책의 모든 목차 항목·예제·연습·해설·출처가 보존됐는지 대조한다. Markdown 구조와 링크를 점검하고, 편집한 부분과 미해결 문제를 인수인계한다.

## 결과 기준

독자는 `book.md` 하나를 열어 전체 내용을 순서대로 읽고 연습할 수 있어야 한다. 다른 파일의 본문을 가리키는 링크만 있는 `book.md`는 완성된 통합본이 아니다. 원고의 전체 설명을 보존한다.

이 스킬은 편집 산출물을 만든다. 최종 내용 검토나 책의 출고 승인, 다음 작업 배정은 수행하지 않는다.
