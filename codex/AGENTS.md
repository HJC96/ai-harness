# Codex Instructions

경로는 별도 표시가 없으면 저장소 루트 기준이다.

## 학습용 책 작업

- 메인 세션은 [오케스트레이터 역할](../orchestration/book-orchestrator.md)과 [집필 흐름](../orchestration/learning-book.md)을 읽는다. 작업 배정·의존성·단계 전환의 기준은 이 두 문서에만 둔다.
- 메인 세션은 역할별 서브에이전트를 사용한다. 직접 학습 설계, 조사, 본문 작성, 내용 검토, 편집을 수행하지 않는다.
- 작업자는 배정된 `codex/agents/*.toml`의 역할과 지정된 스킬을 읽는다. 다른 역할을 겸하거나 팀을 지휘하지 않는다.
- 모든 참여자는 [공통 원칙](../shared/instructions/project-guide.md)을 따른다. 산출물을 만들 때는 [작업 계약](../shared/instructions/book-contract.md)을 읽는다.
- 모델·추론 강도·실행 권한은 현재 세션 설정을 상속한다. 에이전트 파일은 역할과 판단 기준만 정의한다.
- 커스텀 에이전트가 세션에 아직 보이지 않으면, 일반 서브에이전트에 역할 파일의 `developer_instructions`와 스킬 경로를 명시해 같은 역할을 부여할 수 있다. 이는 TOML 설정을 자동 적용하는 기능이 아니다.
- 서브에이전트 실행 도구 자체가 없으면 필요한 실행 환경을 알리고 집필을 중단한다. 메인 세션이 역할을 번갈아 연기해 완료했다고 보고하지 않는다.

## 하네스 유지보수

- 역할·절차·오케스트레이션의 책임 경계를 보존한다.
- 에이전트 판단 기준을 바꾸면 `codex/agents/`, 수행 방법을 바꾸면 `shared/skills/`, 작업 순서를 바꾸면 `orchestration/`를 수정한다.
- `python3 scripts/doctor.py`로 검색 경로, TOML, 스킬 메타데이터, 문서 링크를 확인한다. 설치 스크립트를 바꾸면 충돌 시 기존 파일을 보존하는지도 확인한다.
